# PROYECTO FINAL - SEMILLERO IA

## Asistente Legal Inteligente

Este proyecto consiste en el desarrollo de un **Asistente Legal Inteligente** utilizando **LangChain**, **Google Gemini** y **ChromaDB**. La solución implementa una arquitectura basada en agentes especializados para responder consultas legales, analizar imágenes y registrar solicitudes de manera automática.

## Objetivo

Desarrollar una mesa de ayuda inteligente para el área legal que permita:

- Responder consultas sobre contratos.
- Resolver preguntas relacionadas con protección de datos.
- Brindar información sobre normas de ética y cumplimiento.
- Analizar documentos mediante IA multimodal.
- Registrar solicitudes legales automáticamente.

## Tecnologías utilizadas

- Python
- LangChain
- Google Gemini
- ChromaDB
- Jupyter Notebook

## Agentes implementados

- Agente RAG de Contratos.
- Agente RAG de Protección de Datos.
- Agente RAG de Cumplimiento.
- Agente Multimodal.
- Agente de Acción.
- Clasificador de Intenciones.
- Orquestador.

## Estructura del proyecto

- `Proyecto_Final.ipynb` → Notebook principal.
- `01_Clausulas_Contractuales.txt` → Base de conocimiento de contratos.
- `02_Proteccion_Datos.txt` → Base de conocimiento de protección de datos.
- `03_Cumplimiento_Etica.txt` → Base de conocimiento de cumplimiento.
- `imagen.png` → Imagen de prueba para el agente multimodal.
- `registro_solicitudes_legal.txt` → Archivo generado por el agente de acción.

## Ejemplos de consultas

- ¿Qué cláusulas debe contener un contrato de prestación de servicios?
- ¿Qué dice la política sobre protección de datos?
- ¿Cuáles son las normas de ética de la empresa?
- Registrar contrato.
- Analizar imagen.
